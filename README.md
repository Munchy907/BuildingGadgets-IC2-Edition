I made this mod as I wanted to use building gadgets as a replacement for the builder, filler & other blueprint related stuff not implemented in BC Remeastered. However, it removed the charging table as there wasn't anything that uses it as robots are not implemented and won't be in the future. The only way to enable them again is by enabling debug mode, which is not prefered due to many reasons. Instead of just adding Chargers or Charging Gadgets to my game, as they feel out of place. I made this instead. Overcomplicated I know, can you tell i'm a programmer :P

Building Gadgets... But powered with EU! Also, I made the visual preview only show up if wearing a nano or quantum helmet (can be disabled, enabled by default). This was done as otherwise, it didn't feel realistic and in line with IC2. The gadget themselfs aren't the most realistic to begin with, but I find them extremely useful, so I feel like this is the best compromise.
